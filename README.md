# Python-project
Netflix Dataset Analysis and Machine Learning Predictions

This project explores and analyzes a Netflix dataset using Python (Pandas, NumPy, Matplotlib, Seaborn). It includes:

Data Cleaning: Handling missing values, encoding categorical variables, and feature engineering (like extracting Year and Month from dates).

Data Visualization: Various plots to show genre distribution, content type distribution, yearly additions, budget vs IMDb score, etc.

Machine Learning:

IMDb Score Prediction and User Engagement Prediction using:

Linear Regression

Random Forest Regressor

(Supports easy extension to SVM, Logistic Regression, and other models via sklearn)

Performance Evaluation: Model performance measured by R² score and Mean Squared Error (MSE), with result visualizations.
